### RhinoVLA Technical Report · **7.13**
RhinoVLA is a deployment-oriented Vision-Language-Action model co-designed with the Huixi R1 edge SoC that achieves real-time robotic manipulation by reducing VLM token and computation burden while preserving performance comparable to π0.5.

### Think Like a Pilot: Fine-Grained Long-Horizon UAV Navigation · **6.57**
FLIGHT VLA introduces an asynchronous architecture combining a low-frequency Streaming Pilot VLM for task-state reasoning with a high-frequency diffusion action model for continuous control, outperforming baselines on the new FLIGHT benchmark for fine-grained long-horizon UAV navigation.

_spd 4 · gen 4 · spec 7 · cost –_ · [abs](https://arxiv.org/abs/2606.06836) · [pdf](https://arxiv.org/pdf/2606.06836v1) · [code](https://github.com/buaa-colalab/FLIGHT)

### Robotic Policy Adaptation via Weight-Space Meta-Learning · **6.4**

### Spline Policy: A Structured Representation for Robot Policies · **6.07**
Spline Policy replaces fixed-resolution action chunks in robot policies with spline parameters, enabling compact continuous trajectory decoding, temporal resampling, and principled local correction, while remaining compatible with modern policy backbones.

### Coarse-to-Control: Action-Token Planning for Vision-Language-Action Models · **6.02**
Coarse-to-Control improves long-horizon robot manipulation by having a VLA model first predict coarse action tokens as a plan, then generate fine-grained actions conditioned on that plan, all within a shared discrete action vocabulary.

### Dreaming when Necessary: Advancing World Action Models with Adaptive Multi-Modal Reasoning · **6.02**
